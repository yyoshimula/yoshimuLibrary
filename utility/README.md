# Utility

このディレクトリには、MATLABでの作業を効率化するための汎用的なユーティリティスクリプトが含まれています。主に図の整形・保存、レイアウト調整、および簡単な数学的・論理的ヘルパー関数で構成されています。

## ファイル一覧

### 図・プロット関連

- **`fig4Paper.m`**
  - 学術論文（特にAIAA系）向けに図を整形・保存する関数。
  - フォント（Times New Roman）、サイズ、線の太さ、グリッドなどを論文掲載用に最適化します。
  - `exportgraphics` を使用して高解像度PDFとして出力します。
  - 引数 `asis=1` でレイアウト変更を抑制可能です。

- **`figs4Paper.m`**
  - 現在開いている**全ての**図に対して `fig4Paper` を適用し、一括保存します。
  - UserDataを使用して二重保存を防止する機能があります。

- **`fig4Presen.m`**
  - プレゼンテーションスライド向けに図を整形・保存する関数。
  - 論文用よりも大きなフォントサイズ、太い線、視認性の高い配色を設定します。

- **`gFigs.m`**
  - 開いている複数のFigureウィンドウを指定したディスプレイ上にグリッド状（タイル状）に整列させます。
  - デュアルモニタ環境などで、大量の図を整理して表示するのに便利です。

- **`cls.m`**
  - 全てのFigureウィンドウを閉じます (`close all` のラッパー)。

- **`plotStd.m`**
  - 平均値と標準偏差（±1σなど）をプロットするための関数。
  - エラーバーや影付き領域として標準偏差を表示するのに使用されます（詳細はソースコード参照）。
  
- **`drawShadowZones.m`**
  - 時系列プロット上で、日照条件フラグ (`sunlitFlag`) に基づき、影（蝕）の期間を `xregion` を用いて背景ハイライト表示します。
  - データの可視化において、いつ影に入っていたかを視覚的に分かりやすくするために使用します。

### その他

- **`sb.m`**
  - MATLABの `symbolic` 式を、Scrapbox (Cosense) 用の数式フォーマット（`[$ latex_code ]`）に変換・出力します。
  - 式のメモ書きやドキュメント作成に役立ちます。

- **`ifelse.m`**
  - 三項演算子的な動作をする関数。
  - `result = ifelse(condition, trueValue, falseValue)` の形式で、条件に応じた値を返します。

## 使用方法の例

```matlab
% 全ての図を閉じる
cls

% 何かプロットする
plot(rand(10,1));

% 論文用に整形して保存
fig4Paper; 

% 全ての図を整列させる（プライマリモニタ）
gFigs(1);
```
